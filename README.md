# 📚 University Library Management System (Java)

A comprehensive Java-based Library Management System built to demonstrate core **Object-Oriented Programming (OOP)** concepts.

## 🚀 Features
- **Role-based Access**: Separate menus/features for Students and Librarians.
- **Book Management**: Add, update, view, and manage book inventories.
- **Borrow & Return System**: Track item availability and record user transactions.

## 🛠️ OOP Concepts Implemented
- **Encapsulation**: Private fields with public getters and setters across all entity classes (`Book`, `Person`, etc.).
- **Inheritance**: `Book` extends `LibraryItem`; `Student` and `Librarian` extend `Person`.
- **Polymorphism**: Method overriding for custom implementations (e.g., `displayInformation()`).
- **Abstraction**: Abstract classes (`LibraryItem`, `Person`) defining core structure.
